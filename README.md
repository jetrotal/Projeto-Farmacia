## 💻 Sobre o Projeto
O sistema **Farmarcia** não é apenas um CRUD tradicional, mas sim o coração da operação de uma farmácia focada na terceira idade (localizada na Liberdade/SP). O ecossistema visa unir a acessibilidade física a uma tecnologia de ponta, facilitando o trabalho do farmacêutico e a vida do paciente.

A solução tecnológica será dividida em duas frentes principais:
1. **Frontend Web (React JS):** Focado no PDV (Ponto de Venda) de altíssima agilidade (atendimento < 8 min) e no Dashboard Administrativo para monitoramento das metas do negócio.
2. **Mobile (React Native):** Aplicativo voltado ao cliente final (idosos e cuidadores) com foco extremo em acessibilidade, fontes grandes, e facilidade para solicitar refil de medicamentos de uso contínuo.

A base tecnológica (Backend) será construída em **Node.js** com banco de dados **PostgreSQL**, além de integrar uma Inteligência Artificial via Chatbot (WhatsApp) para leitura de receitas.
